# Python Project Portfolio

A collection of hands-on Python projects, including REST APIs, Flask web apps, desktop applications, and programming exercises.

## REST APIs

| Project | What it does |
| --- | --- |
| [Weather API](./weather_api/) | Returns temperature, humidity, and wind speed from Open-Meteo or OpenWeather. |
| [Products API](./products_api/) | Manages an in-memory product catalog with create, read, update, and delete operations and an optional price filter. |

## Web applications

| Project | What it does |
| --- | --- |
| [Flask Portfolio](./flask-portfolio/) | A personal portfolio website with Home, Skills, and Projects pages. |
| [Flask Form Project](./form_project/) | Demonstrates how to submit an HTML form and handle the submission in Flask. |
| [Task List](./task-list/) | A web application for managing a list of tasks. |

## Desktop applications

| Project | What it does |
| --- | --- |
| [GUI Simple Calculator](./gui_simple_calculator/) | A graphical calculator for basic arithmetic. |
| [Kivy Image Gallery](./kivy_image_gallery/) | Displays a collection of images in a Kivy application. |
| [Countdown Timer](./pyside_countdown_timer/) | A desktop countdown timer built with PySide. |

## Python exercises

| Project | What it does |
| --- | --- |
| [Longest Word Finder](./longest_word_finder/) | Finds the longest word in a piece of text. |
| [3×3 Matrix Addition](./matrix_3x3/) | Adds two 3×3 matrices element by element. |
| [Palindrome Checker](./palindrome/) | Checks whether text reads the same forward and backward. |
