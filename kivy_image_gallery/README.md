# Kivy Image Gallery

A Python image gallery built with Kivy. The application starts from `main.py` and uses the images in the `images/` directory.

## Run locally

From the `kivy_image_gallery` directory, run these commands on Linux or macOS:

```bash
python3 -m venv venv
source venv/bin/activate
python -m pip install kivy
python main.py
```
